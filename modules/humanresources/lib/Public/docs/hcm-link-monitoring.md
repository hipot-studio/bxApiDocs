# MonitoringService — состояние обмена с внешней HCM-системой

Сервис отдаёт сводку обмена заданиями с внешней HCM-системой (1С) по каждой подключённой
компании: работает ли обмен, когда 1С отвечала в последний раз и сколько заданий в каком
состоянии. Сервис только читает и не выполняет ни одной записи.

В сводке нет ничего о документах и сотрудниках — только компании и счётчики заданий.

## Получение сервиса

```php
use Bitrix\HumanResources\Public\Service\Container;

$monitoringService = Container::getHcmLinkMonitoringService();
```

## Права

Сервис не проверяет прав: право на просмотр сводки принадлежит вызывающей стороне.
Проверяйте его **до** обращения к сервису.

## `isAvailable(): bool`

`true`, если интеграция с HCM доступна на портале и подключена хотя бы одна компания.

## `getSummary(): ExchangeSummary`

Сводка на момент сборки.

```php
use Bitrix\HumanResources\Type\HcmLink\Monitoring\ExchangeHealth;

$summary = $monitoringService->getSummary();

$summary->collectedAt;              // Bitrix\Main\Type\DateTime — момент сборки
$summary->portalHealth();           // ?ExchangeHealth
$summary->companies;                // list<CompanySummary>

foreach ($summary->companies as $company)
{
	$company->companyId;            // int
	$company->companyTitle;         // string
	$company->lastAnswerAt;         // ?DateTime — последний успешный ответ 1С
	$company->health();             // ExchangeHealth
	$company->counters;             // StateCounters за месяц — набор для показа
	$company->recentCounters;       // StateCounters за сутки — набор вердикта
}
```

### `StateCounters`

Шесть непересекающихся счётчиков заданий и их сумма `total()`:

| Поле | Задания |
|---|---|
| `waiting` | отправлены, 1С ещё в пределах штатного времени на ответ |
| `notPickedUp` | отправлены, но 1С их не забрала |
| `inProgress` | 1С забрала и работает над ними |
| `unfinished` | 1С забрала, но не дослала результат дольше суток |
| `canceled` | отменены |
| `done` | завершены успешно |

Седьмое поле `canceledByAgent` — подмножество `canceled`: отмены, сделанные агентом после
исчерпания переотправок. В `total()` оно не входит, нужно только вердикту и наружу не
показывается: на экране задание честнее показать просто отменённым.

### `ExchangeHealth`

| Значение | Что означает |
|---|---|
| `NO_DATA` | обмена за период не было: либо заданий нет вовсе, либо 1С ни разу не ответила |
| `OK` | обмен работает: 1С отвечала, признаков поломки нет |
| `UNFINISHED` | 1С забрала задания, но не дослала результат |
| `PARTIAL` | часть заданий не доходит, но успешные ответы есть |
| `BROKEN` | обмен не работает: задания не доходят, успешных ответов нет |

`ExchangeSummary::portalHealth()` возвращает `BROKEN`, только когда компании с заданиями есть
и **все** они в состоянии `BROKEN`; во всех остальных случаях — `null`.

## Окна

| Константа | Значение | Для чего |
|---|---|---|
| `MonitoringService::SUMMARY_WINDOW` | `-1 month` | показываемые счётчики и поиск последнего ответа |
| `MonitoringService::VERDICT_WINDOW` | `-1 day` | вердикт |

Окна разведены намеренно: считая вердикт по месяцу, одно отменённое задание держало бы
компанию в аварийном состоянии весь месяц после того, как обмен починили. Вердикт остывает
за сутки после починки.

Остывание засчитывается только против ответа 1С, и `OK` без единого ответа невозможен. Правило
вердикта по убыванию тяжести:

1. заданий за месяц нет — `NO_DATA`;
2. за сутки есть незабранные или отменённые агентом задания: при успешном ответе за те же
   сутки — `PARTIAL`, иначе — `BROKEN`;
3. такие задания есть за месяц, а `lastAnswerAt` пуст — `BROKEN`: сутки тишины ничего не
   доказывают и поломку не гасят;
4. есть задания, висящие в работе дольше суток, — `UNFINISHED`;
5. `lastAnswerAt` пуст — `NO_DATA`: обмена не было, потому что 1С ни разу не ответила;
6. иначе — `OK`.

Признаком поломки считаются незабранные и отменённые агентом задания. Отмена из мастера
сопоставления в вердикт не идёт: там ждать перестал человек.

## Кеш

Сводка кешируется на 60 секунд общим, не пользовательским ключом, поэтому `collectedAt`
может отставать от текущего момента до минуты. Считать её мгновенным снимком нельзя.
